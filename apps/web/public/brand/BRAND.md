# uniscrims brand

## Files
- `uniscrims-logo.svg` – full logo for dark backgrounds (header, hero)
- `uniscrims-logo-light.svg` – full logo for light backgrounds
- `uniscrims-icon.svg` / `uniscrims-icon-light.svg` – chevron icon only (dark / light backgrounds)
- `favicon.svg` – 32 px favicon with its own dark rounded background
- `uniscrims-avatar-512.png` – Discord bot avatar / social image

The wordmark text is already converted to outlines, so no font is needed to display the logo.

## Colors
| Token | Hex | Use |
|---|---|---|
| background | `#0E1116` | page background |
| surface | `#141820` | cards, panels |
| surface-2 | `#1A1F27` | icon tiles, inputs |
| text | `#F2F4F7` | primary text, left chevron, "uni" |
| text-muted | `#8B93A1` | secondary text |
| accent | `#3D7BFF` | right chevron, "scrims", buttons, links |

## Type
- UI and headings: **Space Grotesk** (500 / 700), Google Fonts

## Rules
- Don't recolor, stretch or rearrange the logo. Use the light variant on light backgrounds.
- Leave clear space around the logo equal to at least the height of one chevron arm.
- Below 120 px wide, use the icon instead of the full logo.
